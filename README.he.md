# אומנות הקשר — אתר המערכת

האתר הציבורי, העברי ו־RTL-first של מערכת „אומנות הקשר”: משאבים פתוחים, הספר, התוכנית בת 12 השבועות וליווי אישי.

## מה נמצא כאן היום

- עמודי למידה ועזרי החלטה שמאפשרים להכיר את הגישה לפני שבוחרים מוצר.
- מסירת מדריכים ומשאבים, עם הפרדה מפורשת בין קבלת מדריך לבין הצטרפות לרשימת דיוור.
- עמודי תוכן ושיווק לספר, לתוכנית, לליווי, לאירועים, לפודקאסט ולמשאבים קשורים.
- ממשק עברי, רספונסיבי ומותאם מובייל, המבוסס על רכיבים נגישים ושימוש חוזר.
- שערים שנכשלים סגור עבור עדויות, תוכן ספר מוגן, רכישה ותהליכים התלויים בספק חיצוני.

בקוד המקומי יש גם routes וחוזים שאינם זמינים בכוונה עד שיושלמו ויאושרו תשתיות ההרשאה, התשלום, ההוכחות או הספקים שלהם. build מקומי שעובר אינו הוכחה לכך שהגרסה נפרסה ל־production.

## עבודה מקומית

נדרשות גרסה נתמכת של Node.js ו־npm.

```bash
npm install
npm run dev
```

שרת הפיתוח זמין ב־[http://localhost:3333](http://localhost:3333).

## בדיקות איכות מקומיות

```bash
npm run lint
npx tsc --noEmit
npm run build
```

בדיקות של ספקים, תשלומים, DNS, דיוור, הזדהות ונתוני production דורשות סביבת staging או sandbox מבודדת. אין להסיק מוכנות ל־production מהפקודות המקומיות בלבד.
