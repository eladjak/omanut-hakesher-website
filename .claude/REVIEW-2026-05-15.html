🛒 אינטגרציית Sumit

Council of Sages פסקו: אופציה c — קישורים סטטיים ל-hosted checkout של Sumit. אפס PCI scope, אפס webhooks לדבג, Sumit מטפל בכל המורכבות (חשבונית מס, מע"מ, חיוב חוזר).

  • configured + live — production URL
  • configured + sandbox — sandbox.sumit.co.il
  • unconfigured — fallback ל-/{product}?checkout=coming-soon

src/components/BuyButton.tsx

קומפוננטה אחת — שלושה מצבים ויזואליים אוטומטית. תומך גם ב-price חיצוני וב-variant=outline. מציג badge "sandbox" כשרלוונטי.

משולב כבר ב-/hadrech CTA. ניתן להוסיף ל-/coaching, /book, /community בקלות.

איך מאמתים שזה עובד עכשיו

בדיקה (sandbox mode)
  1. npm run dev → ידידותית לפורט 3333
  2. פתח http://localhost:3333/hadrech וגלול לסוף
  3. אם SUMIT_CHECKOUT_HADRECH ריק → תראה כפתור "בקרוב" עם 🔒
  4. הגדר ב-.env.local: SUMIT_CHECKOUT_HADRECH=https://sandbox.sumit.co.il/checkout/test-123
  5. הפעל מחדש → תראה כפתור פעיל עם תג "sandbox" כתום
  6. לחיצה תפתח tab חדש ל-Sumit. עסקת test לא תחויב באמת.
