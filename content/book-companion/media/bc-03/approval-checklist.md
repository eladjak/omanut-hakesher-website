# BC-03 | רשימת אישור וקריאה בקול

Status: draft-not-approved

## אישור תוכן וקול

- [ ] אלעד קרא את התסריט בקול לפחות פעם אחת.
- [ ] שאלת העוגן נשמעת טבעית בפה ולא כמו נוסחה טיפולית.
- [ ] כל משפט שאלעד לא היה אומר הוחלף, והנוסח החדש תועד.
- [ ] הדוגמה נשארה בדיונית ואינה מזכירה לקוח, דייט או אדם אמיתי.
- [ ] אין הבטחה שהשאלה תשפר קשר, תגרום לשיתוף או תמנע קונפליקט.
- [ ] עצה אינה מוצגת כטעות תמידית, ושיחה אינה מוצגת כחובה.
- [ ] התיקון ושינוי הבחירה מוצגים כתוצאות תקפות.

## אישור צילום

- [ ] אלעד עצמו הוא המציג והקול היחיד; לא נעשה שימוש בדמות, clone או קול סינתטיים.
- [ ] אין אדם נוסף, מידע אישי, מסך, כתובת או QR בפריים.
- [ ] נשמרו master נקי, room tone ושתי שניות שקט בכל קצה.
- [ ] הקול ברור ואין מוזיקה שמכסה את הדיבור.
- [ ] שני כרטיסי הטקסט ניתנים להבנה גם בלי צבע או תנועה.

## התאמת מסירה

- [ ] הנוסח שנאמר בפועל זהה לתמלול ולכתוביות מילה במילה.
- [ ] הכתוביות נבדקו מול ההקלטה ולא נוצרו אוטומטית ללא תיקון.
- [ ] טקסט החלופה עומד בפני עצמו ונבדק כשהווידאו כבוי.
- [ ] thumbnail קיבל alt text שמתאר את התמונה בפועל לאחר הצילום.
- [ ] `sourceHash` הוחלף ב-hash אמיתי של מקורות ההפקה.
- [ ] נבדקו mobile portrait, RTL, keyboard, 200% zoom ו-reduced motion.
- [ ] אלעד צפה פעם אחת בלי כתוביות ופעם אחת איתן ואישר בכתב.

## קריאה בקול

- [ ] "העניין הוא שפשוט עוד לא בדקנו" עובר בפה בלי להישמע שיפוטי.
- [ ] "הבנתי נכון?" נשמע כמו הזמנה לתיקון.
- [ ] שלוש האפשרויות בשאלת העוגן נאמרות בקצב שאפשר לעקוב אחריו.
- [ ] משפט העוגן אינו נשמע כמו סיסמה או הרצאה.
- [ ] הסיום "זה הכול" נשאר פשוט ולא חגיגי.
