# Book Companion media packages

Register: PUBLIC

שלוש החבילות בתיקייה הן טיוטות הפקה לשלושה עוגנים בלבד:

- `BC-01`: קבלת פנים והיכרות אישית עם אלעד.
- `BC-03`: הדגמה בדיונית של עצירה, בדיקת הבנה ובחירת סוג התגובה.
- `BC-08`: סיום, קהילה ואפשרויות המשך.

אין כאן קובץ וידאו, כתובת ציבורית או אישור לפרסום. כל חבילה נשארת `draft-not-approved` עד שאלעד קורא בקול, מתקן, מקליט ומאשר את התוצאה הסופית.

להרצת הבדיקות:

```powershell
node content/book-companion/media/validate-media-packages.mjs
node content/book-companion/media/test-media-packages.mjs
```
